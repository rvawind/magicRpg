# 《矩阵侵蚀》玩法设计 · 现行版

> **版本：v7-current（2026-11-17 整合）**；作者裁决，game-designer 维护细节，Lead 实现。
> 本文件是现行玩法口径；旧 `介绍_v2.txt`（7×7/3×3 旧设计）已归档，不再作依据。
> 标注【待校订】的数值来自 v7 原文摘要（作者 2026-11-17 粘贴），尚未逐条确认；作者口述优先。

## 1. 核心循环
进入矩阵章节 → 选路线清房/探索/拿奖励 → 侵蚀倒计时 → 激活 BOSS 传送门 → 击败 BOSS → 下一章。
一次 run 多章连续；每章 1 个 BOSS（章节规模/段数仍可调，见 §12）。
切章语义：**逻辑数据（地图/房间/内容）按新章重建；物理槽位池（20）整局持久、不回收不重建，只清 `slot↔逻辑房` 绑定关系**。

### 1.5 章节结构（作者 2026-11-17 定）
- **3 章 × 每章 1 BOSS**；规模 **ch2 > ch1 > ch3**；一次 run 约 30~37 分钟（不含营地，时长为候选值）。
- **第一章**：5×4 包围盒但**稀疏/不规则，配额 13~15 房** = 出生 1 + BOSS 1 + 商店 1 + 村落（任务）1 + **精英 3~4** + **普通房 6~7**；**不含山洞/灯塔/翡翠梦境**；时长约 10~12 min；**倾向合流推进**（新手向）。
- **第一章结束成长目标**：人均 **4~6 件装备 + 等级 8**（作者：极限 lv9~10 可接受；若放 3~4 精英需解决经验冲突，见 §11）。
- **第二章（结构假设，数值待第一章体验后调）**：7×7 包围盒但**不必满格**（24~30 房）；含普通/精英/山洞/灯塔/翡翠/商人等；目标等级 20 + 装备满（暂定）。
- **第三章 = 塔顶（结构假设，数值待调）**：**3~4 房且必含商店**（终局整备 + BOSS）；**BOSS 打完即通关，不给 EXP/成长**；时长约 6~8 min。
- 章节间成长继承；营地/整备阶段保留与否待细化。

## 2. 地图
- 地图 = **房间集合（坐标 (row,col) 可稀疏）+ 显式边列表**；**只允许上下左右 4 向门**，未连通方向随机剪枝，缺格无门。
- 规格**按章节配置**：第一章 **5×4 稀疏包围盒（12~16 房）**、第二章 **7×7 非满格（24~30 房）**、第三章 **3~4 房**；允许缺格/不规则形状，v7 的 6×6/36 房仅测试配置。
- 线框/门连通关系与房间坐标由章节配置提供；UI/测试/文档不得写死规格（质量基线 B11）。
- 内容层：进入房间揭示中心 + 4 向有直连边的邻居房型（3×3 不含对角）——现实现。

## 4. 时间与侵蚀
- 时间轴【待校订】：0:00 开局；0:00~20:00 安全探索；每座灯塔 +80s；20:00 侵蚀开始 + BOSS 门激活；5 分钟覆盖全图；全图后不判负、持续高压。
- 侵蚀逐房推进（从外围沿通道，约 5 分钟覆盖）；被侵蚀房持续扣血（递增）+ 怪物攻击力增强；已清房仍扣血。
- 安全房不免疫：商人仍可交易但需顶着扣血；灯塔被侵蚀后信息失效；翡翠入口关闭；BOSS 房不参与/减半【待定】。
- 侵蚀起点/推进粒度、伤害曲线仍待定。

## 5. 战斗
- 类哈迪斯分波：普通 2~3 波、精英 1~2 波【待校订】；房内不封锁，可随时进出，队友可中途加入。
- 付费退出：离开未清战斗房时，HP≥30% 扣当前生命 20%~30%；HP<30% 免费；最低留 1 点；普通/精英房可用，BOSS 房禁用【待校订；Lead/策划建议改按最大生命固定比例，待作者定】。
- 清房后出奖励祭坛；杀敌金币/经验全图分配；房间奖励需本人到达领取（与个人幸运相关）。

## 6. 死亡与复活
- 死亡留十字架；非 BOSS 房：**十字架存在 15s → 自然消失、玩家自然复活**；击破十字架 → **立即复活**。
- 复活：HP=最大 50%；魔法维持死亡前；30s 伤害降低 debuff，按个人死亡次数 10%/20%/30% 递增【待校订】。
- 侵蚀中自然复活：传送至 BOSS 房入口/安全位置（可看到 BOSS 周边房型，作为信息补偿）。
- BOSS 战：自然复活失效；十字架永续、会回血、受击打断 5s【待校订】；全队同时死亡判负。

## 6.5 回血（作者 2026-11-17 口述）
- **清房回血**：每个怪物房**仅在领取奖励时**，给房内每名英雄**一次性**回复：已损失生命/魔法的 **30%**，保底**最大值的 15%**（封顶补满）；每人每房一次。
- **章节进入回血**：每次进入新章节，回复已损失生命/魔法的 **70%**，保底**最大值的 20%**。
- 公式（作者已确认）：
  - 清房回血：`回复 = min(缺失, max(缺失×30%, 最大值×15%))`
  - 进章回血：`回复 = min(缺失, max(缺失×70%, 最大值×20%))`
  - 生命/魔法分开计算，封顶补满；
  - 续航细节（商店回复品/BOSS 场内回血/精英回血/侵蚀交互）**暂时搁置**（属内容层）。
- 设计意图：续航绑定「领奖励/进新章」，跨章不回满；BOSS 前需管理血量。
- **定位**：WAR3 没有主动叠盾/格挡，伤害硬吃 → 回血是必须的续航底座；压力来自「回血时机受限（领奖/进章）+ 精英/BOSS 硬伤害 + 时间不够」，不是回血稀缺。
- 续航预算（建议，待试玩）：普通房单房战损 ≤30~40% 最大生命（清房回血可覆盖）；精英房战损 50~70%（需后续 1~2 普通房补）；BOSS 战前期望 ≥70% HP（进章回血 + 商店补给）。
- **待作者确认的默认建议**：① 商店卖回复品但每人每章限购 1~2；② BOSS 战不给自动回血、允许限量消耗品；③ 精英房同普通房回血规则（领奖时回，不额外大回血）；④ 侵蚀不压制回血数值（若需压制可做配置项“侵蚀中回血系数”，默认 1.0）。

## 7. 成长与经济（作者 2026-11-17 口述优先）
- 击杀金币/经验**全图分配**（与位置无关）；金币进**个人钱包、个人消费**。
- 清房祭坛：每名英雄各自 **3 选 1**（BUFF/装备共用池）；**必有 1 项来自该角色独有装备池**（适配三围/定位的“不歪”保底），其余可为 BUFF 或共用装备池。
- 装备 = **底材（固定）+ 词条（随机）+ 套装（同名 3/6 触发）**；构筑差异来自词条与套装取舍。
- BUFF **无上限**；可为纯数值/技能等级/计数类（不含触发型词条，触发属于装备词条）；技能等级通过 BUFF 选项提升。
- **道具A 不存在**（旧“学/升技能、刷新 BUFF”作废）。
- 永久增益来自翡翠梦境精英（全队、跨章节）。
- **目前不处理 BUFF/装备内容层**：成长系统 v0 仅记录，不排实现批次。

|---|---|---|---|
| 6 | 15,250 | 15 | 122,500 |
| 7 | 21,700 | 20 | 237,500 |
| 8 | **29,400** | 30 | 待补 |
| 9 | 38,400 | | |
| 10 | 48,750 | | |
| 12 | 73,700 | | |

- **分配**：经验**全图分配 = 每人拿全额**（不是 4 人平分）。
- **普通房前两房固定成长**：第 1 个普通房必升 **lv2**（约 950 EXP）；第 2 个升 **lv3**（约 +1,950）；第 3 房起按怪物等级 1~6 的自然曲线（具体单房 EXP 待补）。
- 来源：普通房怪物等级 **1~6**（不含精英）；精英房 **约 10,000**（≈lv1→lv5；原 12~18k 作废）；山洞等可挑战 BOSS **30,000~50,000**；BOSS：ch1 **15,000~25,000**、ch2 **45,000**、ch3 **不给 EXP**。
- **第一章放 3~4 个精英（可选池）**；等级目标按**期望清理数**校准，不按内容全清：
  | 实际清理（普通 6~8） | 总 EXP 估 | 结束等级 |
  |---|---|---|
  | 精英 0 | 27~42k | lv7~9（偏低） |
  | 精英 1 | 37~47k | lv8~10（贴目标） |
  | 精英 2 | 47~57k | lv9~11（偏上限） |
  | 精英 3~4（全清） | 57~82k | lv10~13（高风险高回报，玩家自愿） |
  结论：**BOSS 强度按 lv8~10 校准**；全清属于玩家用时间/血量换等级，不作为基准。
- **第二章结束目标 = lv20（总经验 237,500）+ 装备满**；进 ch2 约 lv9~10（38~49k），需 ch2 产出约 190~200k。预算：16~22 普通房（48~110k）+ **至少 3~4 个精英**（30~40k）+ **1 个山洞**（30~50k）+ BOSS 45k ≈ 150~245k；中位可到 lv20，低 roll 可能只到 lv18（建议保证精英/山洞数量，或后续上调普通房 EXP）。
- **第三章塔顶**：BOSS 打完即通关，无 EXP/无成长需求。
- **山洞只从第二章起出现**；ch1 不含山洞（待作者最终确认）。
- **EXP = 杀敌奖励，不由房间/章节配置发放**（作者 2026-11-17 明确）：清房不直接给 EXP；EXP 由击杀怪物结算，与房间类型/布局无关。
  - 房间配置只负责：房型、怪物组、怪物等级档、刷新/波次；不配置 EXP 数值。
  - 前两房成长节奏由**怪物组等级/数量**（内容层）控制，不由“房间奖励”实现。
  - 怪物等级按距出生图距离分层（1~2/3~4/5~6 → 怪 lv1~2/3~4/5~6）属内容层设置；具体 EXP 曲线归杀怪奖励系统。
- **第二章/第三章数值暂缓**（作者：做好第一章后按体验调）；ch2 的 24~30 房/lv20、ch3 塔顶均为结构假设。
- 仍待定：第 3 房起 EXP 曲线试玩校准、ch2 怪物等级/EXP 配比、lv20 后 EXP 溢出处理。

## 8. 特殊房间
- **灯塔**：安全房，支付金币激活、全队共享；显示以其为中心**曼哈顿 ≤2 的未探索房型**（12 格，边缘截断）；仅未探索、不改变通行；侵蚀前 +80s；被侵蚀后失效。
- **商人**：安全房；金币购买装备/消耗品；侵蚀后仍可用但房间扣血，不能赖店。
- **山洞**：高收益精英，保证 ≥2 连通门；洞内怪物睡眠/可挑战（作者想法，未定）。
- **墓园**：等效精英，纯数值房（独有机制另议）。
- **翡翠梦境**：安全房，交互进入共享副本（2~3 波精英）；击杀精英给全队永久增益；侵蚀开始关闭入口。
- **BOSS**：位置可见性由章节配置开关控制（默认待定）；侵蚀开始门激活；击杀全队胜利；不可脱出。

## 9. 信息与可见性
- 已探索房显示房型；未探索不显示，除非被灯塔照亮。
- **灯塔/商人/BOSS 的位置可见性一律走章节配置开关**（`showBoss/showMerchant/showSpecialNodes/threatLayer/revealAdjacent`，默认值待作者定）；不写死。
- 战斗状态：房间颜色/边框脉冲表示“有人正在打”，不用文字弹窗。
- 未领取奖励：只显示“有你的未领取奖励”，不泄露内容/品质/价值。
- 不加全图战斗/非战斗粗信息（如需威胁层，作为配置开关，默认关闭）。
- 特殊房/未来任务房/隐藏商人房：类型系统按注册表扩展，不写死房型数量。

## 10. 移动与道具
- 房间间通过门移动；未连通不可走。
- 移动消耗品（商店）：短距（曼哈顿≤2）、同行/同列、指定房；不限制使用场景（可盲踩/战斗中脱出），不免疫侵蚀；BOSS 战禁用。
- 付费退出与紧急穿越：代价与冷却按数值表另配。
