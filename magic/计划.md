# 地图系统重构实施计划（待执行留底）

> 本文件为分步实施记录，每完成一步更新状态。同步的设计文档见 `介绍_v2.txt`。

## 背景

将 Forest 关卡的 13 房间有向图 + 3 秒引导传送，替换为 7×7 网格 Roguelike：
清房才能移动、紧急穿越技能、20 + 1 物理槽位池、信息揭示、曼哈顿诅咒 + 候选 BOSS 房。

## 已锁定决策

1. **方向由位置决定**：每房间 4 个方向矩形（上下左右），各带特效。
   - 正常：房间清空后方向矩形变「不透明」→ 走进停留几秒 → 传送
   - 紧急穿越：站在方向矩形中使用共通技能 → 传送（无需清房）
2. **传送门 = 矩形 + 特效**：复用 exit.j 走进 rect 检测。
3. **类型/奖励预分配**：保留 InitArea 遍历分配。
4. **怪物池持久化**：spawned/killed/alive 跨进入累积，离场删怪断点续刷。

## 各步要点

### 第一步
- `exit.j`：入口矩形检测加「源房已清空或安全区」闸门；停留时长可配置；清房后刷新出口特效。
- `monster_room.j`：`OnRoomCleared` 内调用 `RefreshAreaExitState(areaId)`。

### 第二步
- 新增共通技能：站方向矩形放技能→穿越；代价 20% 当前生命 / 濒死免费但 10s 冷却。
- `monster_room.j`：离场杀怪（保留游标），复入断点续刷。

### 第三步（已实现）
- 新增 `grid.j`（7×7 网格模型，随机 DFS 生成树 + 额外边）与 `slot.j`（20 槽位池：4 地形 × 5，另加 1 个 BOSS 预留槽）。
- `data.j`：逻辑 ID 持久数据、`Area_EnsureBound`（同地形槽位分配）、外围 8 起点与 BOSS 候选。
- `enter.j`：按槽位常驻触发器，逻辑 ID 记账；空闲槽位定时回收（CLEARED/INACTIVE 且无玩家）。
- `exit.j`：门洞矩形瞬时传送，清房/安全区才可通行；紧急穿越复用 `TryTraverse`。
- `monster_room.j`：怪物池按逻辑 ID 持久化，槽位释放时清理实例并回退游标。
- `forest.j`：替换为网格配置；物理房按 `gg_rct_FR_*` 命名注册，门洞矩形自动生成。
- `chapter.j`/`dust.j`：适配新的初始化与重置顺序。
- **待办**：WE 中创建 21 个区域矩形 `gg_rct_FR_A1..A5 / B1..B5 / C1..C5 / D1..D5 / FR_BOSS`，然后编译测试。

### 第四步
