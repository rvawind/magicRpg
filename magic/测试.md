## 通用操作

- **编译**：在 YDWE 中打开地图 → 保存（Ctrl+S 触发 jasshelper 编译）→ 看「编译错误」窗口。无报错即通过。
- **运行**：测试地图（F9 或「测试地图」按钮）→ 观察游戏内左下角消息（`BJDebugMsg`）。
- **日志级别**：`debug.j` 中 `debug_level = 1`（默认），因此 `[DEBUG]` 前缀日志默认**不显示**，`[INFO]/[WARN]/[ERROR]` 显示。
  要看到本清单中标注的 `[DEBUG]` 日志，请临时把 `debug.j` 第 12 行 `debug_level = 1` 改成 `0`，测完改回。

## Step 1：清房才可移动 + 传送门传送

### 1.1 编译
- [ ] 保存地图无 jasshelper 报错（涉及 `exit.j`、`monster_room.j`）。

### 1.2 运行时
- [ ] **未清房禁止移动**：进入一个怪物房（不清空），走到出口矩形 → 不开始引导；开 `debug_level=0` 后应看到 `[exit] channel blocked`；角色仍在房内。
- [ ] **清房判定**：杀光该房怪物 → 看到 `[room] room cleared`（INFO，默认可见）。
- [ ] **清房后特效切换**：清房后，该房出口特效从红色（DoomTarget）切换为传送门（MassTeleportTo）。
- [ ] **清房后传送**：清房后走进出口矩形 → 开始引导（`[exit] channel started`）→ 约 3s 后传送（`[exit] teleport complete`）到目标房。
- [ ] **安全区/入口直达**：在入口房或安全房，走进出口矩形 → 快速通道（约 0.5s）即可传送。
- [ ] **可配置时长（可选）**：在 `forest.j` 的 `InitForest` 临时加 `call SetAreaExitDelay(5.0)`，普通房引导变 5s，验证后移除。

## Step 2：紧急穿越技能 + 怪物池持久化

### 2.1 编译
- [ ] 保存无报错（涉及 `emergency.j` 新增、`chapter.j` 的 include、`forest.j` 的 `SetEmergencyAbilityId`）。
- [ ] 确认跨库函数 `areaEmergency_SetEmergencyAbilityId`、`ResetAreaEmergency` 能解析（无「未定义函数」报错）。

### 2.2 前置配置（物体编辑器，必须）
- [ ] 为所有英雄添加一个**共通技能**：无目标、瞬发（可基于 Berserk/狂战士 这类无目标瞬发技能制作），技能原始 ID 设为 `'A000'`。
  - 若你用的是别的 ID，请同步改 `forest.j` 里 `areaEmergency_SetEmergencyAbilityId('A000')` 的实参。

### 2.3 运行时
- [ ] **正常代价穿越**：未清房时站在方向矩形上施放紧急穿越 → 扣当前生命 20%，瞬时传送到相邻房；日志 `[emergency] traverse X -> Y`（INFO）。
- [ ] **濒死免费**：生命 <30% 时施放 → 不扣血，进入冷却；日志中 `cd=10.0`。
- [ ] **冷却限制**：冷却期内再次施放 → 无效；开 `debug_level=0` 应看到 `[emergency] cooldown active`。
- [ ] **怪物池持久化**：紧急穿越离场后，原房怪物被删除；再次进入原房 → 从断点续刷（`[room] player enter ... state=ACTIVE alive=0 -> resume spawn`，且 `[room] SpawnDelay ... spawned=` 从上次断点继续，非从 0 重刷）。
- [ ] **重置**：关卡切换后，紧急穿越冷却被清空（新关内可立即施放）。

### 3a.1 编译
- [ ] 保存无报错（`grid.j`、`slot.j` 应被编译；库名 `areaGrid`、`areaSlot`、`requires` 依赖无误）。

### 3a.2 冒烟测试（可选，用自定义代码验证）
在 WE 触发器里新建一个自定义代码，跑一次初始化即可验证模块可用：
```jass
call Grid_Init(7, 7)
call Grid_BuildEdges()
call Slot_Init(0.0, 0.0, 512.0, 512.0)
// 观察左下角输出（自行 BJDebugMsg 打印结果）
call BJDebugMsg(I2S(Grid_GetTotal()))          // 应为 49
call BJDebugMsg(I2S(Grid_GetNeighbor(0, 1)))   // DIR_DOWN=1，(0,0)下方应为 (1,0)=7（除非被剪枝）
call BJDebugMsg(I2S(Grid_GetNeighbor(0, 0)))   // DIR_UP=0，越界应为 -1
```
- [ ] `Grid_GetTotal()` 返回 49；`Grid_GetNeighbor` 越界返回 -1、合法方向返回正确 ID（或被剪枝返回 -1）。
- [ ] `Slot_Acquire(0)` 返回非空 rect，`Slot_GetLogicalIdByRect(该rect)` 返回 0；`Slot_Release(0)` 后 `Slot_IsBound(0)` 为 false。
